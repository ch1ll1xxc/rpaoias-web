# Веб-интерфейс РПАО ИАС: запуск

Веб-интерфейс использует **то же Python-ядро CPU**, что и настольное приложение.
Отдельный `index.html` через двойной щелчок не работает: нужен локальный Python-сервер.

## Windows

1. Клонируйте репозиторий
```powershell
git clone https://github.com/ch1ll1xxc/rpaoias-web.git
```
2. Откройте PowerShell **в папке `rpaoias-web`**, где лежат `pyproject.toml` и `run-web.cmd`.
3. Выполните:

```powershell
uv run python -m rpaoias.web
```

Можно также запустить `run-web.cmd`. По умолчанию автоматически откроется браузер по адресу `http://127.0.0.1:8080`.

Для другого порта:

```powershell
uv run python -m rpaoias.web --port 8081
```

Остановить сервер: `Ctrl+C` в терминале.

## Где исходники

- `src/rpaoias/web/static/index.html` — разметка вкладок и визуальной схемы.
- `src/rpaoias/web/static/style.css` — графитовая тема, компоновка и адаптивные стили.
- `src/rpaoias/web/static/app.js` — анимация, стрелки, регистры, ОЗУ, история и управление через API.
- `src/rpaoias/web/server.py` — HTTP-сервер на Python и API.
- `src/rpaoias/web/model.py` — построение потока данных из результатов настоящих шагов `CPU.step()`.
- `src/rpaoias/cpu/` — исходный процессор и ОЗУ.
- `src/rpaoias/assembler/` — ассемблер.

## Проверка

```powershell
uv run pytest -q
```

Сервер слушает только `127.0.0.1`, то есть доступен только на вашем компьютере. Не открывайте его напрямую в публичный интернет.

На вкладке «Потоки данных» схема показывает реальную выборку из ОЗУ, декодирование, вычисление и фиксацию результата. Цветом выделяются чтение, запись, передача данных, адреса и управление. Этапы в интерфейсе — пояснение выполненного шага, а не модель аппаратных тактов. После шага блок «Входы и выход команды» отдельно показывает операнды A/B (и входной CF для ADC) и результат с целевым регистром либо записью в ОЗУ; для CMP показывает изменившиеся флаги. На вкладке «Память» столбец signed16 интерпретирует каждое 16-битное слово отдельно, а над таблицей отображается текущее полное знаковое 48-битное значение RESULT, его HEX-представление и разбиение по словам.

Кнопка «До HALT» выполняет инструкции существующим CPU до команды HALT одним запросом и сохраняет каждый шаг в истории. После завершения откройте «История», чтобы разбирать шаги без повторного исполнения. Предел — 10 000 инструкций за один запуск.
