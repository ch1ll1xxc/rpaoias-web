# Источники и границы заимствования

## Материалы задания

«уч-мет пособие РПАО ИАС практика.pdf», Скрябин Ю. М., Данилович Е. С. Использован предоставленный в разговоре файл, 55 страниц PDF; печатная нумерация 3–57.

Для проекта важны 1.1–1.2 (память и регистры), 2.1–2.3 (адресация, адресность, переходы), 3.1–3.2 (знаковые числа и длинная арифметика), 4.1 (требования), 4.3–4.4 (эмуляция и ассемблер). Таблица 4.1 прочитана по изображению страницы с объединенными ячейками.

Готовые листинги пособия в проект не переносились. Наша ISA, кодирование, программы и исходники спроектированы отдельно. Ошибки и различия явно перечислены в method-notes.md.

## Документация инструментов

При подготовке проверены официальные материалы:

| Материал | Для чего использован | Адрес |
|---|---|---|
| Python 3.13, Built-in Types | Представление int и побитовые операции; модель сама ограничивает разрядность | `https://docs.python.org/3.13/library/stdtypes.html` |
| Qt for Python, QTimer | Запуск шагов через цикл событий, а не блокирующий while | `https://doc.qt.io/qtforpython-6/PySide6/QtCore/QTimer.html` |
| pytest, Parametrize | Параметризованные тесты границ и комбинаций | `https://docs.pytest.org/en/stable/how-to/parametrize.html` |
| uv, Locking and syncing | uv run, отдельный extra gui, создание окружения и lock-файла | `https://docs.astral.sh/uv/concepts/projects/sync/` |
| uv, Managing dependencies | Разделение runtime, optional gui и dev-зависимостей | `https://docs.astral.sh/uv/concepts/projects/dependencies/` |

Проверка документации API не является выполнением GUI-тестов. Фактические запуски и ограничения среды перечислены отдельно в verification.md.
