# Проверка интерфейса с вкладками

Дата: 16 октября 2026 года. Среда: Linux, Python 3.13.5.

## Фактически выполнено

`python -m compileall -q src tests`: проверка синтаксиса прошла.

`python -m pytest -q`: **424 passed, 3 skipped**. Полный вывод: `ui-tabs-tests.txt`.
424 случая включают прежние 397 тестов и 27 новых проверок описания шага.

Проверены все шаги четырех встроенных программ, неизменность CPU при создании описания,
входящий перенос ADC, источники MUL до перезаписи, CMP без записи регистра, SAR на ноль,
чтение по прежнему значению указателя, запись без изменения значения, HALT,
самомодифицирующийся код и обе ветки всех шести условных переходов.
Отдельно проверен случай, когда цель перехода совпадает с адресом следующей команды.

Сравнение с исходной выгрузкой: 22 Python/ASM-файла вне `src/rpaoias/ui/`
совпадают побайтово. Контрольные суммы: `ui-tabs-core-sha256.txt`.

Установщик проверен в отдельном временном каталоге: режим без изменений,
копирование с резервной копией, сохранность ядра, восстановление старых файлов,
удаление добавленных файлов при восстановлении, отказ от неполного проекта,
отказ от выхода за каталог и остановка отката при более поздней пользовательской правке.
Это проверка логики установщика на Linux; запуск установщика в PowerShell не выполнялся.

Пакет успешно собран в wheel. В него попали CLI, новые UI-модули и ASM-ресурсы.
Из распакованного wheel вне исходного проекта запущены `sum` и `dot_product`.
Результаты: 65459 и 2947418113. Графический запуск этим не проверяется.

## Что не проверено

PySide6 отсутствует. Установка с обычного индекса и с PyPI не удалась.
Прямая загрузка wheel тоже завершилась ошибкой.

Три пропуска относятся к модулям `test_ui.py`, `test_ui_tabs.py`, `test_ui_plush.py`.
Они содержат проверки настоящего Qt. Заглушки библиотеки не используются.
Графические проверки не запускались и не считаются прошедшими.
Само окно, внешний вид, применение QSS и взаимодействие на Windows не проверены.
Скриншот нового окна не подготовлен. Ruff не установлен и не запускался.

## Проверка на целевом компьютере

```powershell
uv run --extra gui pytest -q
uv run --extra gui rpaoias gui
```

При доступном PySide6 графические модули должны выполняться без пропуска.
Вручную проверь открытие каждой вкладки, сборку, шаг, пуск, паузу, сброс,
просмотр старого шага без изменения CPU, переход к RESULT, ошибку исходника и сохранение файла.
Также проверь окно при своем масштабе Windows и на небольшом размере.
