# Проверка версии 0.1.0

Дата подготовки: 2 октября 2026 года.

## Что фактически выполнено

Среда: Linux, Python 3.13.5, pytest 9.0.2.


Это 397 успешно прошедших параметризованных/обычных тестовых случаев. Один пропуск относится к модулю GUI: PySide6 в среде отсутствовал, поэтому пять находящихся в нем smoke-тестов окна не запускались. Пропуск не считается успешной проверкой GUI.

Дополнительно выполнена компиляция всех Python-файлов, включая GUI, через `python -m compileall -q src tests`. Она проверяет синтаксис, но не наличие API Qt и не работу окна.

Проверены четыре режима адресации, машинные кодировки, прямые/косвенные пересылки, переходы по обеим веткам, CF/OF, MUL с перекрытием исходного регистра и пары результата, знаковое расширение, ошибки входного текста, ошибки доступа к памяти, остановка HALT и лимит исполнения.

В наборе есть 120 воспроизводимых случайных пар запусков: сумма массива длиной 6..15 и сумма произведений массивов длиной 10. Внутри отдельного теста АЛУ выполнены 3000 случайных сравнений ADD/ADC/SUB с математическими определениями.

Тест единой памяти изменяет будущую инструкцию с NOP на HALT и проверяет, что процессор исполняет измененные байты, а не старый объект из листинга. Тесты аварий проверяют, что ошибочный шаг не меняет архитектурное состояние.

Для последнего случая слова результата low/middle/high равны `0000 8000 0002`. Ненулевая третья часть показывает, почему 32-битного накопителя недостаточно.

## Упаковка

Пакет собран локально в wheel через setuptools. Wheel установлен без зависимостей в отдельное окружение; встроенный `dot_product` запущен из `/tmp`, вне каталога исходников. Результат 2947418113 подтверждает, что `.asm`-ресурсы попадают в пакет и не зависят от рабочего каталога.

## Что не подтверждено

`uv sync --all-extras` не завершился: среда не разрешила DNS-имя сервера пакетов. Поэтому не проверены автоматическая установка зависимостей, PySide6, работа окна, QTimer и ручное взаимодействие с интерфейсом. Lock-файл не сгенерирован и не подменен вручную.

Ruff сконфигурирован, но не запускался: пакет отсутствовал и не был загружен. Проверка на Windows не проводилась. Работоспособность GUI нельзя выводить из успешных тестов ядра.

## Повторная проверка на целевом ПК

```powershell
uv run pytest -q
uv run --extra gui pytest -q
uv run ruff check .
uv run --extra gui rpaoias gui
```

При установленном PySide6 нужно получить успешные GUI-тесты без пропуска этого модуля, а затем вручную проверить открытие окна, выбор примера, сборку, несколько шагов, пуск/паузу, сброс и сохранение исходника. Тесты и документация не являются подтверждением приемки преподавателем.
