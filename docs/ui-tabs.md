# Интерфейс с вкладками

## Запуск

Полный проект запускается из каталога с `pyproject.toml` и `src/rpaoias/cli.py`:

```powershell
uv run --extra gui rpaoias gui
```

В Windows можно открыть `run.cmd`. Интерфейс использует существующий PySide6 / Qt Widgets.
Дополнительных зависимостей эта правка не требует.

## Обновление существующего проекта

Архив `rpaoias_tabs_update.zip` содержит правку, а не полный проект.
Распакуй его в папку `rpaoias_tabs_update` внутри основного проекта.
Команды выполняй из основного проекта:

```powershell
uv run python .\rpaoias_tabs_update\apply_update.py --project .
uv run --extra gui rpaoias gui
```

Установщик проверяет обязательные файлы проекта и контрольные суммы файлов правки.
Перед заменой он сохраняет исходные файлы в отдельную папку рядом с проектом.
Ее путь будет напечатан в терминале. Ядро, программы, `pyproject.toml` и `.venv` не заменяются.

Проверка без копирования:

```powershell
uv run python .\rpaoias_tabs_update\apply_update.py --project . --check
```

Для отката используй `--restore` с напечатанным путем резервной копии.
Автооткат остановится, если после установки ты изменил хотя бы один файл правки.
Это защищает более поздние изменения от перезаписи.

## Основные вкладки

«Программа» содержит исходник, листинг сборки и диагностику.
Выбор встроенного примера, открытие и сохранение находятся здесь.
Розовая строка показывает следующую команду по PC, если машинное слово совпадает с листингом.

«Исполнение» содержит разбор последнего завершенного шага, поля IR и результат.
На странице разбора есть схема «источник → действие → результат» и таблица изменений.
Кнопки этапов меняют только пояснение. Кнопка «Показать разбор» переключает их последовательно.

«Регистры» содержит все R0–R15 и отдельную страницу служебных регистров и флагов.
Значения, изменившиеся на последнем шаге, выделены сиреневым фоном и полужирным текстом.

«Память» содержит единую ОЗУ, метки и обращения к памяти.
Кнопка «К RESULT», адресное поле и двойной щелчок по метке переводят к нужному слову.
Если указан нечетный адрес, выбирается содержащее этот байт 16-битное слово.
В обращениях выборка команд скрыта по умолчанию. Ее можно включить флажком.

«История» содержит до 1000 последних успешно завершенных команд, разбор выбранного шага и текстовую трассу.
Двойной щелчок по строке открывает сохраненный шаг. Текущее состояние CPU не меняется.
Историю можно сохранить в CSV. Сброс CPU и успешная новая сборка очищают историю.

## Что означает визуализация

Одна команда по-прежнему выполняется целиком через `CPU.step()`.
Разбор показывает четыре логических этапа: выборку, декодирование, операцию и запись результата.
Это объяснение уже выполненной команды, не моделирование аппаратных тактов.

Описание использует `StepResult.before`, `StepResult.after`, `memory_writes` и временный снимок памяти до шага.
В историю попадают только необходимые значения и снимки регистров. Целый образ ОЗУ для каждого шага не хранится.
Формулы АЛУ повторно не выполняются: результаты и флаги берутся из CPU.
Для условного перехода пояснение проверяет условие по прежним флагам.
Это позволяет различить выполненный и невыполненный переход даже при совпадении цели с адресом следующей команды.

При ошибке CPU новая запись успешного шага не добавляется. Окно показывает ошибку и последний завершенный шаг.
При изменении кода в ОЗУ используется фактически прочитанное машинное слово.
Прежняя исходная строка не подписывается под измененной инструкцией.

## Управление

Панель «Собрать / Шаг / Пуск / Пауза / Сброс CPU» доступна на любой вкладке.
PC, IR, счетчик шагов и четыре флага также остаются видимыми.
Изменение исходника запрещает исполнение устаревшей сборки.

Сочетания клавиш: Ctrl+O — открыть; Ctrl+S — сохранить; Ctrl+Enter — собрать;
F10 — шаг; F5 — пуск; Shift+F5 — пауза; Alt+1…Alt+5 — основные вкладки.

Декоративный баннер, логотип, название `plush.cpu` и заглушка для рисунка удалены.
Розовая палитра сохранена в `src/rpaoias/ui/theme.py`.

## Проверка

Результаты подготовки находятся в `ui-tabs-verification.md` и `ui-tabs-tests.txt`.
На целевой машине полная проверка, включая Qt:

```powershell
uv run --extra gui pytest -q
uv run --extra gui rpaoias gui
```
